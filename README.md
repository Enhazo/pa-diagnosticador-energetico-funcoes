# Diagnosticador Energético (versão com funções)

Versão em C++ do exercício de monitoramento de consumo energético por setores e dias, estruturada com funções.

## Compilação

Projeto desenvolvido para Windows. Compile `diagnosticador-energetico-funcoes.cpp` em um compilador C++ para Windows.
